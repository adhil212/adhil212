### 🌐 System Overview & Bio

Full-Stack Developer with production-grade experience architecting scalable web systems using the **MERN stack** — spanning RESTful API design, JWT/OAuth authentication pipelines, and real-time WebSocket data streaming. My engineering approach is rooted in **structured problem-solving, modular system architecture, and cross-functional collaboration** within Agile/Scrum delivery cycles.

Currently operating as a **Full-Stack Developer Intern at Bridgeon Solutions**, where I own end-to-end feature delivery across 15+ full-stack capabilities — from responsive frontend interfaces through production REST API endpoints to cloud-deployed backend infrastructure. I've designed authentication systems from scratch, optimized database performance through strategic indexing, and eliminated component re-renders at scale through Redux Toolkit state restructuring.
